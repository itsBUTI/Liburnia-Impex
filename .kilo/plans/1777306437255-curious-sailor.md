# Dark Mode Implementation Plan

## Goal
Convert the entire Liburnia Impex website to dark mode by default (no toggle switch).

## Strategy
1. Update CSS design tokens (CSS variables) in `src/index.css` to dark mode equivalents
2. Ensure all components use these variables consistently
3. Verify and fix any hard-coded colors that don't adapt to dark mode
4. Adjust any specific dark-mode adjustments needed for images, shadows, etc.

## Detailed Tasks

### 1. Update Design Tokens (`src/index.css`)
Replace the `:root` variables with dark mode palette:
- `--color-primary`: Keep as dark background (#111111 or slightly lighter)
- `--color-secondary`: Darker variant for depth
- `--color-accent`: Keep the accent color (#e63946) for buttons/links
- `--color-text-dark`: Change to light text (#ffffff or #f0f0f0)
- `--color-text-medium`: Light gray for secondary text
- `--color-text-light`: Lighter gray for disabled/hint text
- `--color-bg-white`: Change to dark surface (#1a1a1a or #222222)
- `--color-bg-light`: Slightly lighter surface for cards/elements
- `--color-bg-lighter`: Even lighter surface for hover states
- `--color-bg-gray`: Dark gray for input backgrounds
- `--color-border`: Darker border for separation
- `--color-border-light`: Lighter dark border
- Keep semantic colors (success, warning, info) but adjust if needed for dark mode visibility

### 3. Global CSS Checks
- Search for any hardcoded color values (hex, rgb, rgba) that aren't using variables
- Common places: borders, backgrounds, text colors, shadows
- Replace with appropriate CSS variables

### 4. Image and Asset Considerations
- Existing images may need review for dark mode visibility
- Logos: check if they have transparent backgrounds and work on dark
- Icons: if using SVG or font icons, ensure they have appropriate colors
- No immediate changes required unless user reports issues

### 5. Testing Strategy
- Visual inspection of all pages in dark mode
- Check contrast ratios for accessibility
- Verify hover states, transitions, and animations work correctly
- Ensure text remains readable on all backgrounds
